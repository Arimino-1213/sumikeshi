# 墨消し 測定結果と判断の記録（2026-11-03）

## 結論

- 無料の Cloudflare Pages で配信し、OCR と検出はすべて利用者のブラウザの中で動かす形で作った。書類は外に出ない。
- **未知の書類での実力は「隠すべき語の 86.6% を自動で隠せた」**（3回・1128語の合計）。残り約13%は人の確認が必須。
- 既知の形（直したあとの書類）では 94.7〜99.0%。未知の型ほど下がるので、当てにしてよいのは 86.6% の方。
- 漏えい検査は別の道具でも問題なし（文字データ0件・付帯情報0件・仕込んだ隠し文字の残り0件）。

## 測り方

- **書類**：架空の書類 18種類×2版×4つの状態＝144件。実在の個人情報なし（電話は未割当の形、メールは example.com、住所は実在の市区＋架空の町名）。
- **4つの状態**：文字データ付きPDF／きれいな画像（200dpi）／スキャン風（傾き・ノイズ・汚れ）／スマホ写真風（台形のゆがみ・背景・影）。
- **判定**：正解の文字の位置に実際の画素を重ね、「どの1文字についても黒い部分が5%以上残らない」とき隠せたとする。枠の面積ではなく、本当に見えるかで判定している。
- **対象の設定**：場面は「全部」、「念のため」扱い（最初は隠さない）のものは数えない。
- **実力確認**：検出の調整に使っていない書類で、型も氏名・住所の候補も変えて初回の1回だけ測った。結果を見て直したあとは、別の新しい書類に替えて測った。

## 学習機能

歯止めと確認結果（`tests/regress.mjs` と `tests/e2e/learn_flow.mjs`、画面で24項目すべて合格）：

- 確実（high）の候補は変わらない。変わった候補は必ず要確認に出して理由を表示する

## 仕様の判断と要確認

1. **最初に選ばれている場面は「全部」**。隠し過ぎは見て戻せるが、見落としは戻せないため。変えるのは `public/js/app.js` の `scene: 'all'` の1か所。
2. **当事者の会社名**：「全部」では隠し、ほかの場面では隠さない。法務省の資料は法人名を原則対象外としている。既存の類似ツールには隠す側のものがある。`public/js/detect.js` の `corp-party` の1行で変えられる。
3. **`noindex` を付けている**：検索に出ない。検索に出すなら `public/index.html` の1行を消す。
4. **手書き・顔写真・QR は自動で探さない**：画面の「見つけられないもの」に明記。

## 過去データへの影響

新規のアプリで既存データはない。公開後に検出ルールを変えても、書類を保存していないので遡及の対象はない。すでに書き出したPDFには影響しない。

## 名前の切れ方の総当たり（11/3 追加）

辞書が名前を「悠／斗」「大／翔」のように分けると、名前の一部しか隠れないことがありました（画面で「長男■斗」と残った不具合）。名前60個×言い回し8種の480通りを `tests/sweep_names.mjs` で数えました。名前はすべて例示です。
